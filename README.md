# AI Home Doctor Web Prototype

発表資料のスマホ画面イメージをもとにした、画面確認用の静的Webアプリ試作です。

## 起動

依存関係はありません。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` をブラウザで開いてください。
