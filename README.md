# HomeDoctor Demo Studio

3つのデモをトップから選択できる静的モックです。

- `#mini/home`: P.5 Phase1。温湿度統計、赤外線検知履歴、交換管理、通知。
- `#placement/map`: P.6 設置位置提案。リスクマップ、撮影サンプル、再現間取り。
- `#house/dashboard`: P.4 統合画面。mini状態管理、エアコン・空気清浄機操作。

実装は `index.html`、`demo.css`、`demo.js`。依存ライブラリはありません。
操作状態はページ内で保持し、再読み込みで初期化されます。撮影画像はサンプルイラストで、AI解析・実機連携は行いません。
GitHub Pagesには上記3ファイルだけを配置します。参照PDFや作業用ファイルは公開対象外です。

以下は旧プロトタイプの記録です。

発表資料のスマホ画面イメージをもとにした、画面確認用の静的Webアプリ試作です。

## 起動

依存関係はありません。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` をブラウザで開いてください。
