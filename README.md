# HomeDoctor Demo Studio

3つのデモをトップから選択できる静的モックです。

- `#mini/home`: P.5 Phase1。温湿度統計、赤外線検知履歴、交換管理、通知。
- 温湿度は24時間・7日間・1カ月・1年で切替。`climate.js` / `climate.css` が担当します。
- 2026/09/13を基準とする固定サンプル。キッチン下で8/20〜9/9に21日間高湿度が継続し、2週間・3週間時点の通知とグラフを連動させています。70%の閾値とリスク評価はデモ用です。
- `#placement/map`: P.6 設置位置提案。リスクマップ、撮影サンプル、再現間取り。
- デモ2は2階建て住宅。1F/2Fの切替、家具・家電配置、6か所の設置候補、6枚の生成写真を表示。
- デモ2の間取り・写真データと描画は `placement.js`、スタイルは `placement.css`。
- `#house/dashboard`: P.4 統合画面。mini状態管理、エアコン・空気清浄機操作。

実装は `index.html`、`demo.css`、`theme.css`、`demo.js` と `assets/`。依存ライブラリはありません。
操作状態はページ内で保持し、再読み込みで初期化されます。室内写真はAI生成サンプルで、実際のAI解析・実機連携は行いません。
赤外線検知は部屋別のサンプル回数を日別グラフと時刻別履歴に表示します。照度は入力に含みません。
GitHub Pagesには上記のWeb用ファイルと画像だけを配置します。製品写真は提供PDF P.5の指定部分を使用し、PDF全体や作業用ファイルは公開対象外です。

以下は旧プロトタイプの記録です。

発表資料のスマホ画面イメージをもとにした、画面確認用の静的Webアプリ試作です。

## 起動

依存関係はありません。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` をブラウザで開いてください。
